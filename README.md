Pokemon API CLI Tool
​A command-line interface tool that fetches Pokemon data directly from the PokeAPI and saves it locally.
​Features:
​Search for any Pokemon by name.
​Download specific information including stats, sprites, and official artwork.
​Automatically manages folder collisions by creating unique directories.
​Prerequisites:
​Node.js installed on your machine.
How to Use:
run a cli tool using node prompts.js
then follow the prompts to enter Pokemon name and Information you want to download.
